mssql-readonly-mcp @VERSION@ (@RID@)

An MCP server that lets an AI assistant read one on-premises SQL Server database.

This folder holds a self-contained build: the .NET runtime is included. The program is
mssql-readonly-mcp (mssql-readonly-mcp.exe on Windows) in this folder.

Configuration, the read-only login it needs, commands, exit codes and how to register it with an MCP client:
https://github.com/oguzhanpisgin/mssql-readonly-mcp
